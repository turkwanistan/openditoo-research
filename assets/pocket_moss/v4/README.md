# Pocket Moss v4 — art/animation pass

Generated by `tools/moss_v4_art.py` from one shared head/ear/face/body/tail model, so anatomy stays consistent across poses.

Keeps the v2/v3 face vocabulary (floppy dark-brown ears, bright tan face, cream muzzle/chest, black eyes and 2 px nose, pink tongue). Changes: front-facing seated body instead of the 3/4 body, face centred on the eye axis, top-left highlight / right-side amber shadow, teal collar with gold tag, blue sleep Z's.

Animations: Look (blink + head turn), Loaf (perk, lie down, blink), Sleep-Wake (drifting Z's, yawn), Pet (lean, squish with blush, wags), Dance (crouch, sway, hop, squash landing, wag), Kisses (lean + tongue, heart grows, pops to sparkles, wag). All Pixel Lab warning-free.
