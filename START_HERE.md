# OpenDitoo — Start Here

1. Read `PROJECT_STATE.md` first. It is the current canonical human-readable synthesis.
2. Treat `artifacts/` plus its hash/provenance files as the authority for acquired binary/document evidence.
3. Read `README.md` for the preserved-artifact inventory.
4. Preserve the evidence labels in `PROJECT_STATE.md`; related Tivoo/Ditoo-family evidence is not exact Ditoo Plus truth.
5. Before any physical work, use the preservation rules and first-session plan in `PROJECT_STATE.md`.
6. Do not flash, transmit arbitrary proprietary commands, or guess MassBoot/test-mode combinations merely because static firmware proves those paths exist.

Current top offline targets: MassBoot key ID 3, GPIO `0x1E`, and exact `0x99` firmware-data dispatch.
